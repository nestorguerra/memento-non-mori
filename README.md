# Memento non mori

Revista de ciencia de la longevidad en español, creada por **Alma Guerra**.

[Ver la revista](https://nestorguerra.github.io/memento-non-mori/)

Esta edición contiene **34 noticias**, con una publicación científica y una imagen conceptual distinta para cada pieza. Cada artículo identifica su fuente, fecha, modelo y límites. La biografía incluye las seis fotografías reales facilitadas para esta publicación.

## Publicación

Sitio estático servido con GitHub Pages desde la raíz de la rama `main`. El archivo `.nojekyll` conserva los recursos sin transformaciones. Los enlaces son relativos y funcionan bajo la ruta del proyecto.

La web permanece disponible sin depender del ordenador del autor. Los cambios enviados a `main` se publican mediante GitHub Pages. La búsqueda automática, la redacción y la generación de nuevas noticias en la nube todavía no están activadas.

## Contenido y fuentes

Los textos se preparan con asistencia de IA a partir de resúmenes y metadatos científicos citados. Los investigadores y centros mencionados no avalan ni colaboran con esta revista por el hecho de aparecer en ella. Las ilustraciones de noticias son conceptuales; no son imágenes experimentales.

- [Fuentes científicas](https://nestorguerra.github.io/memento-non-mori/fuentes/index.html)
- [Criterio editorial](https://nestorguerra.github.io/memento-non-mori/criterio-editorial/index.html)
- [Alma Guerra](https://nestorguerra.github.io/memento-non-mori/alma-guerra/index.html)

Las tipografías incluidas conservan sus licencias SIL Open Font License en `assets/fonts/`. Este repositorio contiene únicamente la edición pública; no incluye credenciales, originales de las fotografías, archivos de investigación internos ni copias de recuperación.
